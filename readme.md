# DWP Front End Developer Exercise

A simple personal details form built using HTML, CSS and TypeScript.

## Install

```bash
npm install
```

## Build

```bash
npm run build
```

## Run

````bash
npm start

Open the local URL shown in the terminal, for example:

http://localhost:3000

## Test

```bash
npm test
````

## Possible future improvements

If this application were developed further, possible improvements could include:

- Persist submitted records using a backend or browser storage.
- Provide immediate field-level validation feedback as users correct invalid input.
- Add confirmation before deleting a record.
- Implement pagination when the table contains many entries.
